# Timofei — connected work

This replaces the rejected first visual direction. It follows the user's Continue style guide while retaining a separate personal identity.

## Tokens
Canvas `#08080a`; raised surface `#141416`; text `#ffffff`; secondary text `#b5b5c0`; action `#7147ee`; light accent `#e8e0ff`. Manrope is self-hosted, including Cyrillic. Display 48–100 px, section 32–56 px, body 16–18 px, useful labels at least 12 px. Tracking no tighter than -0.04em.

## Composition
The name and specific work lead. A spatial CODY illustration occupies the other half of the first screen, with visible project and session context. Projects follow as broad, asymmetric exhibits, each with one readable technical artifact. Audience routes are visible near the introduction. Long case analysis follows a compact overview and the relevant local demonstration.

## Interaction
One scene changes with native scroll progress; text and links stay fixed in normal document flow. CODY state changes respond to explicit controls. No section-by-section entrance animation. A visible reduced-motion control complements the operating-system preference. On mobile, shorten spatial movement, use normal flow, keep controls large.

## Character
Specific engineering decisions replace abstract slogans. The signature is a pair of open, connected frames, not the Continue product's logo. Purple means a selected state or action; it is not a wash over every heading. No invented metrics, endorsements or production screenshots. Synthetic interfaces are labelled illustrations.

## Why this fits
The previous first screen could have belonged to any consultancy and hid the actual person. This screen names the developer, shows his project and gives a visitor a concrete way to inspect it. The borrowed palette serves the user's stated visual preference; project content supplies the distinct identity.
